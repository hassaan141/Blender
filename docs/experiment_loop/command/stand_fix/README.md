# Unified-policy stand-only repair campaign

Parent is retained unified loop 6. Maximum six new attempts. The only objective is an upright zero-command stand using the existing `STAND_SOLVED` pose; locomotion behavior is a hard regression constraint.

Each attempt records one diagnosed cause, one targeted change, source snapshot, checkpoint, full 60-second ten-case evaluation, stand and nine-command videos, metrics, visual review, decision, protected check, and SHA-256 manifest. A checkpoint is retained only when the stand is visibly upright and still and the existing W/S/A/D/diagonal battery is preserved. No physics, URDF, gains, effort limits, teacher checkpoints, historical loops, or protected baselines may change.

Stand acceptance: exact `STAND_SOLVED` feedforward target; zero command; frozen phase after command slew settles; no fall; all four paws supporting; body height consistent with the validated 0.182 m stance rather than the loop-6 0.1695 m play-bow; low settled joint velocity/action movement; no visible crouch or lean. Numerical gates do not replace visual review.
