# Bingo documentation

The current animation pipeline remains defined by the [pipeline specification](BingoMocapPipelineSpec.md), [robot specification for animators](Bingo_Robot_Spec_for_Animation.md), and [animation guide](Blender_Animation_to_Robot_Motion_Guide.pdf). Stage 1–5 assets and implementation are unchanged; start at the [repository guide](../README.md).

The sole active locomotion handoff is the root [BASELINE 1 bundle](../BASELINE_1/README.md). Historical forward, natural-walk, AMP, backward, turning, unified, and stand-fix records are preserved under [`archive/baseline_1_provenance/`](../archive/baseline_1_provenance/).

For the progression, representative successes/failures, and a searchable inventory of preserved videos, use the [locomotion history guide](locomotion_history/README.md).
